```shell

```
2. 安装 Flutter：https://docs.flutter.dev/get-started/install
3. 构建应用：https://docs.flutter.dev/deployment

## 介绍

### 内置漫画源

Pica Comic 内置了 6 个漫画源：
- picacg
- e-hentai/exhentai
- jmcomic
- hitomi
- htcomic
- nhentai

### 特色
浏览漫画
在线阅读
下载漫画
管理本地收藏和网络收藏
数据同步（使用 webdav）
阅读历史

### 历史
该项目最初作为 picacg 的非官方应用开始 后来发展成支持多个漫画来源的应用。
